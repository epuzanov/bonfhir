[![npm](https://img.shields.io/npm/v/@bonfhir/mui)](https://www.npmjs.com/package/@bonfhir/mui)

```bash npm2yarn
npm install @bonfhir/mui
```

The `@bonfhir/mui` package provides renderers for [MUI (Material UI) v5](https://mui.com/material-ui/).

It only uses components from MUI, and will integrate very well with a Material Design application and all other MUI components.

[MUI must be installed and configured in the application](https://mui.com/material-ui/getting-started/installation/) for the renderers to work properly - in particular the `@emotion/react` and `@emotion/styled` peer dependencies.

We recommend that you use one of our templates to get started easily.  
Just run `npm create -y bonfhir@latest` to get started.
